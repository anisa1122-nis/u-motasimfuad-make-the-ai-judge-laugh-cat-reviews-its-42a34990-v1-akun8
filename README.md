# Cat Reviews Its Human — Entry

One funny single-line one-star review from a house cat about its
human, under 200 characters.

## How it works

`main.py` writes the review to `/output/entry.txt`.
Stdlib only, offline, deterministic.

## The review

> One star. He bought me a bed. I sleep in the box it came in. He still hasn't learned.

85 characters, one line.
